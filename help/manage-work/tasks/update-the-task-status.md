# Update task status for accurate reporting

The video provides a tutorial on how, why, and how often to update the task status.

>[!VIDEO](https://video.tv.adobe.com/v/3471167/?quality=12&learn=on&enablevpops=1)

## Key takeaways

* **How should you update the task status?** There are several places where you can update the task status. The most common is in the tasks list on the project page.
* **Why is it important to update the task status?** Timely and accurate project and task reporting depends entirely on status updates from individual contributors. Without consistent updates, visibility suffers, decisions stall, and progress risks going off track.
* **How often should you update the task status?:** Update the status of all tasks you're working on at the end of each work day. This will keep the project and task reports accurate to within a day.
