# Understand financial access

The video explains the role of a system administrator in managing access to financial information within Workfront. ​ The administrator controls access through access levels.​
The video emphasizes that users can only use their financial access on projects they create or on projects where someone with financial access has shared it with them.

>[!VIDEO](https://video.tv.adobe.com/v/3457731/?quality=12&learn=on&enablevpops=1)

## Key takeaways

* **Role of System Administrator:** The system administrator manages access to financial information through setup and access levels, ensuring control over who can view or edit financial data. ​
* **Creating Access Levels:** An access level can be created to grant users permissions to edit and view billing, cost rates, exchange rates, and expenses.
* **Project-Level Financial Access:** Users with financial access can edit financials in projects they create, but others need explicit access to view or edit financials.
* **Customizable Access Sharing:** Financial access can be shared with specific users, with tailored permissions (e.g., view-only access), even if they have general rights to edit financial data.
* **Access Limitations:** Users can only use their financial access on projects they create or on projects where someone with financial access has shared it with them.
